# 新闻审核验收入口

当前人工单样本入口为 [news_api_sample_v2](news_api_sample_v2/README.md)：独立计划、单独授权、遮罩输入和最多一次请求。默认 prepare/inspect 不显示凭据窗口、不发网络请求。旧 v1 保留作为历史失败尝试的可复核实现，不复用已消费计划。

真实样本、授权、凭据和运行数据库均不放入源码仓库；只公开必要的代码、合成测试与安全验证摘要。输入窗口只显示字符数，不能据此判断密钥是否有效。

完整核心交付与实际审核结果见 [验收记录](../docs/NEWS_DELIVERY_ACCEPTANCE.md)。真实单次成功、语义准确性、生产自动审核、来源恢复和全天连续稳定性分别判断。
