# 房间讨论流程政策

`workflow_policy` 是每个房间自己的动态讨论边界。主持 AI 可以在边界内选择下一位成员，但不能绕过服务端的阶段、职责覆盖、预算与用户确认规则。

## 可编辑内容

- `stage_order`：讨论阶段顺序。
- `minimum_stage_coverage`：每个阶段至少需要多少位不同成员成功发言。
- `required_coverage`：必须听到的职责；一位成员可通过立场 `stance` 或专业能力 `capabilities` 匹配。
- `minimum_successful_members`：整轮至少需要多少位不同成员成功发言。
- `max_turns_per_member`：单个成员在一轮中的发言上限。
- `follow_up_budget`：完成首轮覆盖后，主持人最多追加多少次追问或修订点名。

模板只是创建和恢复默认值的来源。通用房间默认使用 `facilitate → flexible → decision` 三阶段，要求主持、反证和候选方案整合覆盖；默认方案架构师带 `decision_synthesis` 能力，但名称、身份、职责、边界、阶段、能力和模型都可由用户编辑。美国存储产业投委会的正式模板合同要求 12 个独立职责：

1. 投资委员会主持人；
2. 存储周期分析师；
3. 硬盘产业分析师；
4. 基本面分析师；
5. 技术与资金分析师；
6. 新闻与情绪分析师；
7. 多头研究员；
8. 空头研究员；
9. 数据质量官；
10. 模拟交易员；
11. 风险经理；
12. 投委会决策经理。

数据质量官属于分析阶段的独立必达职责，不能由技术分析师或主持人兼任。它必须核验同轮 `snapshot_id`、市场时间、资料确切版本和轮次冻结截止时间，拒绝晚于截止时间的行情、历史行、财报、新闻或材料；暂停恢复只能沿用原轮冻结数据。无法证明时间有效时按缺失处理，不补值、不猜测，也不允许未来数据进入研究、回测或模拟观察。

当前默认模板、默认政策和相关测试已统一到 12 个职责。兼容迁移只会为旧存储房间补一次数据质量官，并仅在房间仍使用未经修改的旧默认政策时升级为 12 人政策；用户自定义政策不会被覆盖，用户之后主动移除的角色也不会被反复加回。真实 12/12 轮次仍需单独验收，不能只凭静态配置视为完成。

正式 12 角色隔离验收还要求房间显式保存 `moderator_member_id`。验收器按正式成员 ID 将主持映射到临时数据库中的克隆成员，并复核轮次检查点及每条 `director_attempt` 都使用该成员；不会用“流程首位成员”自动回退来替代正式主持配置。

## 轮次与身份版本

新轮开始时，服务端把完整政策冻结进轮次检查点。房间政策可以在讨论期间编辑，但只影响下一新轮；暂停后恢复仍使用原轮政策、资料和市场快照。

成员身份、立场、阶段和能力标签不按整轮冻结，而是从该成员下一次发言开始生效。每条 AI 消息保存发言时的成员版本；收敛检查读取该版本，因此成员发言后再改成某个职责，不会让旧发言冒充新职责已经覆盖。

## 会前配置门

前端和服务端使用同一类确定性检查，确认房间当前启用成员至少能够满足政策规定的阶段覆盖、职责覆盖和不同成员总数。配置缺口会禁用新轮入口；即使绕过界面直接请求，服务端也会在读取行情、探测模型、创建轮次或写入消息之前返回 `ROUND_WORKFLOW_PREFLIGHT_FAILED`，并列出具体缺失项。

这道门检查房间组织结构，不把临时的本轮成员筛选当成永久配置。临时筛选或成员运行失败可以产生明确标记的不完整轮次；收敛门仍按真实成功发言计算，不会把“已配置”误报成“已覆盖”。暂停恢复继续使用冻结政策，同时检查当前启用的房间角色结构，避免用户在暂停期间移除唯一必达岗位后无提示地继续。

## 不可修改的安全边界

以下字段由服务端强制固定，客户端无法关闭：

```json
{
  "user_confirmation_required": true,
  "execution_capability": "none",
  "live_trading_allowed": false
}
```

政策只能组织研究、证据复核、回测和模拟观察，不能授权下单、支付、投注或其他资金动作。

存储产业完整轮的正式最低要求是 12 位不同角色成功发言，并且数据质量官通过防未来数据泄漏检查。用户可以编辑角色文字、模型和边界，但若删除或合并正式职责，界面必须明确把该轮视为自定义流程，不能继续宣称通过“12 角色投委会”验收。

## 校验与兼容

- 阶段、立场和能力使用小写 slug；`follow_up` 是系统保留阶段。
- 非法字段、越界数字、重复覆盖 ID 或空选择器会被服务端拒绝。
- 旧数据库会自动增加政策与能力字段，并按房间模板回填默认政策。
- 房间列表、详情、模板目录和轮次检查点都返回结构化政策，不向客户端暴露数据库 JSON 字符串。
