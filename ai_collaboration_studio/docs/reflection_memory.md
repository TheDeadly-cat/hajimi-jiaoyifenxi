# 结果反思记忆

## 目标

反思记忆让智能体从已经真实结算的模拟观察中复盘，但不允许把模型生成的解释、未确认草稿或单个命中结果自动变成“经验规律”。

## 状态流

```text
用户确认观察 → OPEN → 富途真实日线结算 → RESOLVED
                                          ↓
                                  自动创建 DRAFT 反思
                                          ↓
                         用户填写教训 / 限制 / 下一次验证
                                          ↓
                                  用户确认 CONFIRMED
                                          ↓
                           仅进入以后新建轮次的冻结上下文
```

- 反思只在观察已由用户确认并真实结算后创建。
- 自动草稿只有结果事实和默认因果警告，不自动生成教训。
- 确认前必须填写“本次教训”和“下一次验证条件”。
- 修改已确认反思会生成新版本并退回 `DRAFT`，在再次确认前从未来上下文移除。
- 暂停轮次继续时沿用原检查点，不读取暂停后新增或修改的反思。

## 审计绑定

每条反思永久绑定：

- 原观察 ID、房间、标的、方向、期限和阈值；
- 原依据、反证、模型置信度和证据 ID；
- 富途真实基准价、基准时点和快照 ID；
- 到期价、到期时点、实际收益、命中状态和结算说明；
- 同一快照的同行基准、同行到期收益、目标相对收益和独立相对命中（数据可用时）；
- 上述来源快照的规范化 JSON 与 SHA-256 指纹；
- 每次草稿修改和用户确认的完整版本快照。

确认时会重新计算当前观察结果指纹；若结果与反思来源不一致，确认被拒绝。

## 提示边界

未来轮次只读取最近的用户确认案例，并明确标记为“不可信外部证据”：它们不能改变系统规则、不能证明因果、不能替代 20 个独立样本的统计门槛，也不能触发真实交易。
