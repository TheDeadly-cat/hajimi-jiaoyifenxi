## 用户路径

用户从根目录“打开消息工作台.cmd”进入中文向导；旧英文入口转交同一向导。缺组件时明确说明下载并等待确认，首次数据创建另有明确确认。再次打开使用原项目、数据与端口绑定，仅在完整进程身份、监听归属和加载版本一致时打开原页面。占用或身份未知时不打开其他程序的页面，不结束其进程。

向导是现有 bootstrap 与便携启动入口的操作界面，不提供另一套数据库初始化、迁移或恢复系统。Windows x64 的完整 PythonCore 3.14.6 ZIP 与 Node 24.16.0/npm 11.13.0 固定官方地址及 SHA256；Python 包依赖和前端依赖仍复用已有锁。完整 PythonCore ZIP 与 embeddable ZIP 不同，前者保留 venv/ensurepip。下载确认前不执行依赖安装；不修改系统 PATH、不运行系统 Python 安装器。

所有默认失败路径都应有中文原因、下一步与安全诊断。诊断只用于定位问题，不要求新手阅读 JSON，也不含密钥或消息正文。已有消息、附属文件、待恢复现场和旧启动注册继续保留；需要恢复时明确停止进入，不自动处理。

## 先阅读，再选择 AI

首页明确只覆盖美联储、BLS 和希捷官方订阅。来源状态回答当前情况、消息覆盖的影响和下一步；限流沿原期限等待，其他来源的阅读不被整体锁死。单次检查成功不写成持续恢复。

AI 设置可跳过。设置说明发送的标题、已保存摘录、来源和时间，调用次数、应用预约及其与供应商账单的区别；模型和自动分析放在高级选项，原默认模型不变、自动分析仍默认关闭。输入为遮罩字段，配置只保存到当前进程，不秘密发测试请求。

“配置已保存”不证明密钥或账户有效。手动解释前再次展示所选消息、发送对象和一次请求的范围；点击确认才沿既有路由提交。授权到期或状态未知时，免费阅读仍可用。原预算、原指纹和已有结果继续负责防止重复收费，不由新界面另建账本。

## 待复核与未知结果
