# 消息工作台：当前交付与使用范围

日期：2026-10-19。本页是当前交付入口；10 月 14 日审计文档保留为历史快照。

## 打开与日常使用

双击原桌面“AI 共创室 - 交易分析”，或交易分析目录中的 `run_ai_collaboration_studio.cmd`。首页为消息工作台；“讨论房间”可返回原协作功能。

持续抓取默认每 15 分钟检查美联储、美国劳工统计局和希捷官方订阅。当前公司覆盖仅为希捷，不代表全部美股。发布时间、发现时间、来源状态和失败原因分别显示；订阅标题和摘录不等于核验过的全文。

消息详情可带入用户明确选择的讨论房间，先预填共享资料，再由用户核对并保存。取消不保存，不会随此动作自动抓取原文或调用模型。发布时间缺失仍保持未知，发现时间不会替代发布时间。

“运行记录”提供心跳、来源检查和中断记录，也可设置登录当前 Windows 账户后恢复。电脑必须保持开机、联网、不休眠。这个设置不保存或恢复 AI 密钥。实际连续 24 小时运行与真实重新登录验证仍独立记录，不能用消息数量或短时检查代替。

## 版本、数据和恢复

本交付目录：`ai_collaboration_studio_daily_20261019_r2`。上一版 `ai_collaboration_studio_daily_20261019` 及更早版本保留。正式数据继续位于交易分析目录的 `ai_collaboration_studio/runtime`；程序副本和演练数据与其分开。

本轮源码、构建、检查和入口切换身份见交易分析目录下 `output/news-platform-workflow-20261019-r1/DELIVERY-RECEIPT.json`；该回执在实际交付完成后生成。上一轮运行恢复证据保留在 `output/news-platform-reliability-20261019-r1`。回退需要核对准确版本及后台状态，并使用对应入口备份；不要删除数据库、WAL/SHM 或恢复记录来“修复”启动。

本版本在自身 `runtime/bootstrap` 目录按锁建立运行环境，不借用旧候选的虚拟环境；底层 Python 仍依赖本机安装。源码归档排除数据库、密钥、运行环境和构建目录，不能当作双击即可运行的独立安装程序。正常 bootstrap 应只对全新无链接目录执行，不能借由现用环境的目录链接修改旧版冻结依赖。全新目录的安装启动与合成回退，不等于全新电脑完整安装验收；是否实际通过，以本轮回执为准。
