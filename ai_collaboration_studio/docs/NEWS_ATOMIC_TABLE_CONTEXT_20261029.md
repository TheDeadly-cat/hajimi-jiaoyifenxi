# 表格证据包的完整上下文分组

原事实阅读路径按“前几段＋前几行表格”重排并截取单段，通用包逐行入选；市场输入还会再把表格行作为单例筛选。这些规则可能只保留数字而丢掉表头、期间、单位和脚注。

本次新增共享的纯函数分组规则 `whole_document_table_context_v1`。保存的结构中尚无可验证的跨表脚注、续表和单位依赖关系时，同一含表格文档的全部段落、表格和说明作为一个完整上下文组。不用正则猜测单位或按重复脚注号强行关联。MU 样本的 table-1 依赖远处定义，table-9 是续表，table-10/11 与后续说明有关，因此不能证明单张表就是最小完整组。

事实阅读、通用证据包和市场输入的二次选择都保留组边界、原始段落定位、来源 URL、表/行定位、单元格文本及 colspan/rowspan。读取成功的附件使用独立文档标识；未读附件不进入材料。单元格与行文本冲突、正文与段落缓存不一致、缺定位、缺结构、部分或截断表格均整组省略并记录原因。

预算按最终输出 JSON 的 UTF-8 字节计量，事实阅读另保留原正文文本预算。预算不足时整组省略，不回填单行，也不让 RSS 摘录把孤立数据带回。低于元数据最小大小时明确失败，不超出调用者预算。普通非表格段落也只完整选择。通用包上限 12,000 字节、市场输入上限 8,500 字节及供应商请求上限保持不变；事实阅读新增完整输入上限 12,000 字节，同时继续满足 6,500 字节默认正文预算。

MU 保存页的离线全上下文输入含 256 个段落/表格行、11 表、214 表格行和 1,696 个单元格。完整 JSON 为 240,056 字节，正文 UTF-8 为 21,387 字节。**在当前默认预算下，这份 MU 财务上下文整组省略，未宣称已进入模型输入。** 高预算结果只是本地边界验证产物，未发送请求或提高生产预算。没有可信小组依赖时，不能用拆散财报来绕过预算。

离线试验验证完整字节预算恰好足够时全组选中、少 1 字节时全组省略，正文预算同样验证；保留原文、跨表单位、期间和远距脚注，定位可回到原段。市场二次预算的整组行为由本地小样本回归覆盖，真实 MU 默认路径验证全部省略且不回填摘录。证据目录为 `offline-mu-context-groups-20261029-*`。
