# 共享资料抓取与文件解析

## 支持范围

- 手工笔记。
- 公开 HTTP/HTTPS 网页：HTML、纯文本、Markdown、CSV、JSON、XML、DOCX、文字型 PDF。
- 本地上传：TXT、MD、CSV、TSV、JSON、HTML、XML、DOCX、文字型 PDF。
- 文件最大 2 MB，网页响应最大 1.5 MB，单份提取文本最多 50,000 字符；截断状态会写入来源元数据并显示在资料列表。

PDF 依赖 `pypdf`，通过 `python -m pip install -r requirements.txt` 安装。加密 PDF、超过 80 页的 PDF 和没有文本层的扫描件会被明确拒绝；当前不进行 OCR。

## 来源记录

每个解析版本记录：

- 原文件名或原 URL、最终 URL。
- MIME、原始字节数、提取方式和提取时间。
- 原始来源 SHA-256 与提取文本 SHA-256。
- PDF 页数和内容是否因上限被截断。

原始上传文件不写入 SQLite。当前版本保存在 `materials`，每次抓取、替换或手工修订的完整快照保存在 `material_versions`。版本列表 API 提供审计摘要，单版本 API 可取回完整历史文本和来源元数据。

## 新闻与公告证据元数据

新闻、公告、研报和社交观点可以记录以下结构化字段，并随资料版本一同冻结：

- 来源类型：公司投资者关系、监管文件、可信媒体、分析师研究、社交媒体、内部笔记或其他。
- 来源层级：由服务端依据来源类型派生为 `primary`、`secondary` 或 `unverified`，客户端不能自行把低等级来源改成高等级。
- 发布者、发布时间、事件类型，以及与 `US.MU`、`US.SNDK`、`US.WDC`、`US.STX` 的多标的映射。
- 发布时间只接受有效日期，或包含 `Z` / UTC 偏移的 ISO 时间。没有可靠时间时保持“未知”，不根据抓取时间猜测发布时间。

这些字段会进入智能体的共同资料上下文。新闻与情绪角色应优先使用一手来源，明确区分事实、媒体解释和社交观点，并在事件级正反证中引用真实资料 ID。来源层级是审计提示，不代表内容必然正确。

## 官方事件一键冻结

存储产业房间会列出当前 SEC EDGAR 申报与四家公司官方 IR 新闻稿。用户点击“冻结为资料”后，浏览器只提交证据类型、白名单标的和官方 URL；服务端必须重新从当前可信目录中精确匹配该 URL，随后生成资料标题、索引正文、来源层级和官方证据 ID。客户端不能把任意网页伪装为官方证据，也不能自填官方正文。

- SEC 资料保存 accession number 作为去重 ID；公司 IR 资料使用官方 URL 的稳定 SHA-256 摘要作为去重 ID。
- 同一房间重复冻结同一条证据返回已有资料，不新增重复记录。
- 冻结的是官方事件索引、摘要和核验边界，不是对完整原文的本地镜像，也不自动得出方向结论。
- 冻结后资料进入正常的 `materials / material_versions` 流程，AI 必须使用真实资料 ID 引用；用户后续编辑仍会生成新版本。
- IR 与 SEC 的日期关联候选随资料保存，但只是一条核验线索，不代表两者已经确认描述同一事件。

## 网页安全边界

- 只允许 `http://` 和 `https://`。
- 只允许标准 80/443 端口。
- URL 不得包含用户名或密码。
- DNS 解析后的所有地址都必须是公网地址；拒绝本机、私网、链路本地、保留地址和 `.local` / `.internal` 域名。
- 每次重定向和最终 URL 都重新执行同样校验。
- 请求不携带 Cookie、用户登录状态、模型密钥或任意认证头。
- 限制响应 MIME、声明长度、实际读取长度和连接超时。

这套限制降低 SSRF 风险，但不能把任意网页视为可信内容；来源仍需由用户判断。

## 提示注入边界

抓取内容保持原文，不通过删除关键词假装“净化”。服务端在每次新增或更新资料时重新扫描正文，客户端提交的 `prompt_injection_risk` 不能覆盖扫描结果。只要精确版本命中改变身份、泄露秘密、调用工具或资金动作中的任一类风险，该版本就进入强制隔离：

- 原文和来源链接仍保存在本机版本记录中，供用户查看和审计。
- 原文、URL 不进入正式轮次、空闲点名或自动会议整理的模型上下文，也不能作为该轮正常资料引用。
- 模型只看到包含资料 ID、标题、版本与白名单风险标记的隔离占位；占位明确不构成证据或指令。
- 轮次清单在 `quarantined_materials` 中冻结内容哈希、快照哈希和风险标记。恢复时重新读取精确版本并重算风险；哈希、标记或正常/隔离分桶发生漂移时失败关闭。
- 旧清单没有 `quarantined_materials` 字段时按空列表读取；但实际已经命中风险的版本不能继续伪装成正常资料。

隔离是提示完整性防线，不替代服务端的无交易工具、密钥隔离、只读市场适配器和引用校验。
