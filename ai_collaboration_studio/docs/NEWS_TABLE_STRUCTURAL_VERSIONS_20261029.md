# 表格结构变更的版本识别

此前版本指纹只有标题、摘录、正文文字和附件文字，未包含单元格跨行、跨列关系。正文文字不变而 GAAP 等表头的覆盖范围改变时，会被误判为无变化。

本次规范材料投影加入表分组、行序、单元格文本、`td/th`、`rowspan/colspan` 及结构截断状态，覆盖正文和已保存附件证据。段落编号、表格编号的具体命名、行定位编号、抓取时间和提取器版本名不作为事实变更。两个缓存视图中的表格结构不一致时保存待复核状态。

相同规范材料重复保存不会新建版本或任务。结构发生变化时追加版本，记录 `changes.field=table_structure`，生成独立证据包并保留原快照。旧快照即使沿用不含结构的旧哈希，也从其已保存证据重建材料比较，避免升级指纹算法本身制造重复版本；原哈希和快照不改写。

已存在非空正文但旧版缺结构、结构重新丢失、同一原始字节被重新解释，以及旧材料在另一版本后重新出现时，保存新观察并待复核，不自动排入付费分析。首次从摘录取得正文仍遵循既有证据扩展规则。未变化的未读附件不会使父正文“同一字节”的依据失效。历史 `completed/unknown/failed` 状态不自动重试。

等价结果的回溯按同一材料投影沿连续父版本检查，跨结构变化即停止。别名缓存的目标必须处在已验证的祖先集合中。进入结构身份后，后续失去结构也不会退回旧包身份；A→B→A 使用新观察身份并待复核，旧 A 的结果仍留在旧 A，不能显示为当前版本的新复核。

离线试验使用已有 MU FY2026 Q3 页面，原始 SHA256 为 `ca82922d9a4ac60436ea272972ac0777850f2d643fffb12594cc9d9062faaa82`。测试在新目录复制字节，仅构造一个 GAAP 表头跨列变化及其跨行变化，提取正文文字保持逐字一致。这些变体是本地测试材料，**不代表美光实际发布过更正**。手工导入测试数据库明确为保存页面夹具，不伪造 RSS 抓取成功。

试验验证相同内容和定位信息变化不新建版本、仅跨度变化追加版本、旧版本字节不变、原始失败留存、历史状态不重试、重新打开及按历史时间读取一致。所有来源请求和项目模型入口均禁止；模型结果读取边界用本地预置记录验证，不创建分析客户端，不调用生成器。

证据另存 `offline-mu-table-versions-20261029-*`，回归结果另存 `evidence/mu-table-versions-regression-r1`。此前正文修复报告与原始失败均不覆盖。本次不证明新来源可用性、附件阅读、模型质量或生产安装，也不改变上一轮尚未验收的“截短模型证据包应保留完整表头组合”事项。
