# MU 财报正文提取的离线修复

已保存的 FY2026 Q3 美光公告包含完整正文，但旧版提取器把外层 ASP.NET `form` 及其全部子节点隐藏，返回 `fetch_failed / empty_or_insufficient_body`。页面根节点的 `PageNewsPressrelease` 类名也会被旧的宽泛正文匹配规则误识别。

本次 `official-html-segments-v2` 做了以下修复：

- 允许页面包装表单内部的明确正文容器被读取；继续隐藏搜索表单、正文内的交互表单、脚本、模板与输入控件。匹配完整标记，优先选择公告正文而非通用 `main`。
- 惰性解析有界 JSON-LD，仅接受身份绑定当前公告 URL 的 Article/NewsArticle 时间；记录字段来源路径。时间无时区、身份不匹配或相互冲突时，不猜测时间，也不以抓取时间替代。
- 保留表格编号、行序、单元格文本、`td/th` 与跨列/跨行信息，包括空白占位。无法完整解释的结构或截断内容保持部分读取状态。
- 升级抽取版本，原始字节、旧失败回执、旧报告、请求账本及隔离数据库均保留。
