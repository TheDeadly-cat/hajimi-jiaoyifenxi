# 固定合成基准的关注程度与输出结构

固定合成基准需要区分事项的研究关注程度、正文审阅是否完成，以及现实真实性和市场影响。当前修订在 `d3f312231b97474ce33696c3dea9af505e76ea1b` 后增加结构样板和条件性资本事项说明，仅修改合成准备器、其测试及本文。新策略尚无实际模型输出，不能宣称质量改善已经通过。

## 事项与证据范围

正文可识别的业绩、指引（包括维持）、资本计划（包括附条件拨款、拟建设施或产能）、治理、会计审计和经营风险用 high。主体、项目、预算等补充细节未知，宜保留为具体局限，不单独把已经识别的资本事项降为 uncertain。high 不表示真实、突发、利好利空或交易建议。

常规分红、无财务更新活动仍用 normal；正文无法识别事项、只有未确认时间或指令文字时仍用 uncertain。不能照抄路由或一律 high。正文支持主要内容时用 reviewed；主要内容依赖未读附件或缺失数据时仍用 material_insufficient，不能依据附件名称补出事项或重要性。缺失、截断正文仍不发送。

数值、币种、数量级、期间、条件和版本继续保留，尤其区分计划与已付、产能与产量、可能达到的金额与确定上限、公告发布时间与事项生效时间。正文与引文仍是不可信资料；其中指令不能授权网络、工具或交易行为。

## 合法JSON样板与精确引用

`QUALITY_OUTPUT_TEMPLATE` 是合法JSON结构示例，其中分类、正文内容和 ID 都是待替换占位值，不是参考答案或实际模型响应。提示明确事实使用 `paragraph_id`，推断和反证使用 `paragraph_ids` 数组，禁止改为 `paragraphs` 或以单数代替数组。

facts 聚焦事项事实，不要求把栏目标题或合成声明重复作为事实。合成及未读范围仍必须保留在 limitations；合成声明本身不单独构成对材料内事项的实质反证。真正存在的正文反证仍须保留并引用；没有实质推断或反证可使用空数组。列表最多12项，limitations 非空。

所有段落 ID 仍须从输入逐字复制，禁止缩写、重造或删改哈希；quote 仍须是所指段原文的连续子串。严格验证器不变，不做模糊匹配、字段别名转换、自动补 ID、结果修复或模型重试。

两项新增离线测试把实际提示中的JSON样板代入合成正文后，交由原生严格验证器检查，并分别确认单数 ID 与 `paragraphs` 别名被拒绝且原结果未被修复。占位分类不属于合法审核结论，模板不含任何真实段落身份；模型仍必须自行按给定正文生成内容。测试仅证结构与拒绝路径，不能证明模型将遵循提示或内容达到9分。
