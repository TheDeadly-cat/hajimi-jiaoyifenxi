# 固定合成基准的任务定义与段落身份

固定合成基准要求评价给定材料内事项的关注必要性和已读主 HTML 的主要内容。材料是否合成、现实真实性是否核实以及未读附件的范围限制，都须准确保留；这些限制本身不能代替对给定内容的审阅。段落引用还须逐字对应请求里的段落身份，即使引文文字存在，错误的段落 ID 仍应拒绝。

本修订从质量范围候选 `ae8209445cb1ebd4ed98102b6f1051242aab812e` 建立独立后续候选，将任务定义移到提示开头，并明确字面段落 ID 要求。只有合成准备器提示、准备器测试和本文改变；自然新闻提示、验证器、原始案例、已签核参考、原输出、评分程序、执行器及额度保持。此次新策略尚无实际模型输出，不能把提示修改当作质量提升已获证明。

## 具体行为

提示首先定义材料内事项的关注必要性与主要内容审阅，再描述限制与输出契约。经营、财务、治理或披露时间异常可以需要关注；常规事项可以为 normal，无法判断材料内事项时为 uncertain。模型须独立说明依据，不能照抄路由，也不能把所有合成案例统一提升为 high。

reviewed 表示正文支持的主要内容已归纳，未披露的细节仍写未知。主要结论依赖未读附件或缺失数据时，仍须 material_insufficient，不补写附件。合成声明、真实性未验证和通用 partial 警告继续进入 limitations；它们本身不是材料内事项主张的反证，无原文反证时 counterevidence 为空。

输出字段、枚举、列表上限和非空局限要求写入提示。facts 的 paragraph_id 和 inferences／counterevidence 的 paragraph_ids 均须从输入逐字复制，不增删哈希字符；quote 须为对应段落原文的连续子串。模型结果仍交给未修改的严格验证器，提示没有增加模糊匹配、自动修补或重试。

不可信资料与提示注入、禁止网络补写和交易建议、数字／币种／数量级／期间／条件／版本保留，以及旧公告发现与新事件、时间异常与已确认时点的区分继续要求。

这份说明只供固定合成基准使用。自然事件仍使用 `news_review_contracts.INSTRUCTIONS`，不能因本修订降低真实消息的证据要求。

## 新身份与旧批准

准备器使用独立 `QUALITY_STRATEGY_SHA`，由基准范围、完整新提示与原自然审核策略摘要共同形成。当前基准策略 SHA-256 为：

`796dae482f30d92946375770b0307a299aab4306b87d298b932c95ed6d7b8cc6`

原策略 `edff07be89e42a8c8dd0f3deb3b099af9bb481fb90cd25cca4bb11f60129c7e5` 保持自然审核用途。完整请求、请求 ID、准备结果及未来执行方案随新提示重新绑定，不能复用旧实际请求回执、评分、批准摘要或过期窗口。

已签核参考的正文、案例、范围与摘要匹配时继续复用，不要求重新签核全部参考。未来新实际输出须另行人工评分，不能继承用户对旧 36 项实际输出的采纳。

## 离线验证

沿用既有隔离测试入口、临时 runtime／数据库及网络守卫。新增一项拒绝测试：正确段落 ID 与给定引文先通过；仅给段落 ID 插入合成错字、保留同一有效引文时，仍返回 unsupported_quote。既有断言全部保留。最终七模块合计 97 项回归通过，执行期间生产与测试源码摘要未变，实际完成 footer 和退出码核对一致；网络审计的连接、阻断及模拟连接计数全部为零。既有静态基线 7 项通过。本地结果绑定本轮源码，远端 CI 仍须按实际新提交另行核对。

相对 ae 候选的离线投影，36 项输入和正文版本保持一致，除 instructions 外模型请求字段完全一致；36 个请求身份全部改变。两个缺失／截断案例继续不发送，重复、修订及恢复动作保持。参考答案仍不进入模型请求，原评分门槛与执行器策略保持。投影不是实际发送记录。

每个请求比 ae 提示增加 157 字节，最长 4,076 字节，小于原 4,096 字节上限。按原价格参数，保守预约从 2.401326 元变为 2.435238 元，仍在原 2.50 元上限内；总预约 204,273 tokens，小于原 207,072 上限。仍为 36 次请求、输出最多 1,400 tokens、原固定豆包模型及 Responses 端点，不增加预算、调用数、重试或来源。这是应用估算，价格未在本轮独立核实，也不是供应商账单限制。

首轮回归命令误用了两个不存在的模块，保留失败记录后按真实清单更正。正确七模块的首次执行有一项新增断言错误：异常消息是通用描述，unsupported_quote 在异常的 code 字段中；已改为核对 code，准备器 13 项通过。未删除拒绝断言、修改验证器、依赖、CI 或测试运行器。

## 尚未完成

此新策略没有实际模型输出、人工质量评分或执行授权方案，未打开历史实际数据库。离线工程检查只能验证准备、契约、额度、身份及评分路径，不能证明模型将正确理解新说明或达到 9 分。

后续必须在新提交、准确 CI、具体窗口、预算和本机密钥输入绑定后取得新响应；Q30 仍须把关键未读附件作为材料不足，缺失／截断仍不发送，所有数字、单位、期间、条件、版本和提示注入约束继续核对。不得删除合成警告、塞入参考答案、放宽阈值或自动重试来使成绩变绿。

该候选独立提交审阅，不合并到新闻采集候选；历史输出、分数和运行失败各自保留，不转移到本策略。没有因本修订取得自然消息验收、账单核验、独立事实核验或发布批准。
