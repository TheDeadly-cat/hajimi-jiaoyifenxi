# 存储行业供需代理边界

## 第一批官方序列

系统通过 FRED 的固定公开 CSV 端点读取五条美国官方月度序列，不需要 API 密钥：

- `U34BVS`：美国计算机存储设备制造商出货额，来源为 Census M3。
- `U34BTI`：美国计算机存储设备制造商总库存，来源为 Census M3。
- `PCU3341123341121`：计算机存储设备生产者价格指数，来源为 BLS PPI。
- `PCU334413334413`：半导体及相关器件生产者价格指数，来源为 BLS PPI。
- `CAPUTLG3344S`：半导体及其他电子元件产能利用率，来源为 Federal Reserve G.17。

适配器只允许代码内固定的 `https://fred.stlouisfed.org/graph/fredgraph.csv?id=...`，验证最终重定向、CSV 表头、响应大小、有限数值与非未来日期。每条序列独立失败、独立报错，完整结果缓存六小时；不会用搜索结果、新闻数字或模型估计补值。

## 派生指标

库存与出货额在同一月份都有有效值时，系统复算 `库存 / 当月出货额`。它保留原始月度观测并明确标记为派生值。比值上升可能来自库存增加，也可能来自当月出货下降；两条序列均未季调，季节性明显，因此不能把单月变化直接解释为“补库”或“去库”。

所有原始序列只计算相邻、3 个观测和 12 个观测的变化率，不生成综合供需评分、方向标签、胜率或仓位。

## 口径限制

- NAICS 334112 是计算机存储设备制造口径。Census 的分类说明明确把半导体存储器芯片归入 334413，因此它更接近设备侧代理，不能当作 DRAM 或 NAND 芯片价格。
- NAICS 3344 / 334413 覆盖广泛的半导体及电子元件，不是存储芯片专用序列。
- 这些序列是美国行业月度数据，存在发布时间滞后、修订、季节性和地域限制；不能代表全球现货或合约市场。
- `MU`、`SNDK`、`WDC`、`STX` 的主营结构不同。代理必须与公司主营构成、财报、SEC 原文和反证一起使用，不能直接外推到单家公司收入、利润或股价。

## 执行边界

适配器只下载公开 CSV，没有账号、订单、交易上下文或资金能力。共同快照保留序列 ID、官方链接、截止月份、单位、范围和错误；富途、FRED 或任一公司资料缺失时均显式降级，不生成替代事实。
