# 宿主前端视觉刷新（2026-08-12）

本次刷新采用“证据控制台”方向：深石墨导航轨、冷灰纸张画布、靛蓝行动色、青绿色验证状态色。目标是让重复使用的协作工作台更容易扫描，不把研究工具做成营销首页，也不改变任何领域证据、用户决定或 Provider 授权语义。

## 可见改动

- `frontend/src/styles.css`
  - 统一 shell、导航轨、房间侧栏、会话头部、历史工具栏和 Composer 的层级、圆角、边框与焦点状态。
  - 对话画布增加低对比度网格纹理，消息气泡和空状态获得清晰但克制的层级。
  - 保留足球、股票、证据图和治理面板自己的领域颜色；移动端重新确认侧栏/检查器的原有抽屉行为。
- `frontend/src/components/ChatTimeline.jsx`
  - 空房间新增“本地证据工作台”引导，明确证据优先和用户确认后执行，不自动触发任何动作。
  - 仅复用现有 `lucide-react` 图标，不增加依赖。
- `frontend/src/App.jsx`、`frontend/src/components/RoomInspector.jsx`、`frontend/src/components/ActionDeskPanel.jsx`
  - “查看全部行动 → 打开对应行动台”不再依赖固定帧延迟，而是把目标与单次请求编号交给 lazy-loaded 检查器。
  - 检查器在显式导航后短时观察布局变化；上方异步面板继续展开时会重新对齐目标，稳定 900 ms 后结束，最迟 4 秒强制清理。
  - 目标行动台可由程序聚焦但不进入顺序键盘导航，移动端会避开固定标题栏。

## 验证

- 前端单测：`318/318` 通过。
- Vite 构建：`1673 modules`，成功；主入口约 `482.39 kB`，无大块 chunk 警告。
- 默认浏览器预览：首屏层级、错误提示、空状态和 Composer 正常。
- 移动端 `390×844`：文档宽度与 body 宽度均为 `390`，无横向溢出；房间列表和检查器仍由原有抽屉门控。
- 隔离高密度样例：从“受阻”行动筛选进入第二个房间后，移动端目标顶边对齐在 `52 px` 标题栏下；桌面端行动台完整可见，焦点落在目标区，控制台 warning/error 为 `0`。
- 浏览器验收使用系统临时 runtime 与显式临时 SQLite；Provider 调用、市场读取和出站连接均保持 `0`，未启动正式 `8770` 或 Futu/OpenD `11111`，也未访问正式数据库。

## 交互边界

- 空状态只是说明性内容；不会创建房间、发消息、启动轮次或写入授权。
- CSS 改动没有放宽 disabled、focus-visible、错误提示或用户确认状态。
- lazy-loaded host surfaces 及其显式授权清理逻辑保持不变。
- `ResizeObserver` 只在一次显式导航期间存在，并在稳定、超时、目标变化或组件卸载时清理，不形成常驻布局监听。
