# 富途只读数据边界

## 目标

富途只为研究房间提供可追溯的美股市场证据。当前白名单是 `US.MU`、`US.SNDK`、`US.WDC`、`US.STX`。每个讨论轮次只生成一次完整证据截面，随后所有智能体共享同一个 `snapshot_id`。

## 数据质量

- 快照保留富途的美东市场更新时间，并转换为 UTC 时间供系统比较。
- 盘中实时口径保持严格：有效价格只有在市场更新时间不晚于抓取时刻、且年龄不超过 20 分钟时才标记 `quote_is_live=true`；未来时间一律为 `future`，不会查询市场状态来绕过。
- 有效但超过 20 分钟的行会在同一个 `OpenQuoteContext` 中对本批次标的一次性调用 `get_market_state`。只有富途明确返回 `AFTER_HOURS_END`、`CLOSED` 或 `WAITING_OPEN`，且年龄不超过 96 小时，才可标为研究就绪；96 小时覆盖美国三天长周末从周五收盘到周二开盘前约 89.5 小时的正常间隔，超过上限失败关闭。
- 闭市提升后的行保持 `quote_is_live=false`，并显式携带 `market_state`、`freshness_basis=closed_session_latest_snapshot` 和 `research_ready=true`；界面称为“最近闭市截面”，绝不称实时。市场状态为开市、缺失、查询失败或返回行不完整时继续标记 `stale`。
- Readiness、前端会前门和服务端 convergence 使用同一失败关闭合同：研究就绪行只能是 `quote_is_live=true + freshness_basis=live_20m_window + 0 <= age <= 1200 秒`，或 `quote_is_live=false + freshness_basis=closed_session_latest_snapshot + 明确闭市状态 + 1200 < age <= 345600 秒`。服务端还会用 `captured_at` 与行时间复算年龄，和声明年龄相差超过 1 秒即拒绝；旧版仅有 `quality=ready` 而缺少新鲜度字段的记录返回 `MARKET_SNAPSHOT_FRESHNESS_INVALID`，不能继续准入。
- 权限、SDK、OpenD、连接和标的缺失分别返回明确的错误码。
- 上游失败时 `rows` 为空，不使用模拟价格或其他来源静默替换。
- 状态接口区分“SDK 未安装”和“SDK 已安装但导入失败”；日志目录权限等导入错误不能被误报成缺少 SDK。
- 历史日线限制在白名单内，单次最多 500 条，并过滤未来时间行。
- 快照正股字段保留总市值、净利润、EPS、PE、TTM PE、PB、每股净资产与股息字段；`equity_valid=false` 时不输出这些值。
- 技术指标使用前复权日线确定性复算：1/5/20 日收益、SMA20/50、RSI14、20 日年化已实现波动率、20 日成交量比和最大回撤。每行携带样本数、截止时间、公式版本与缺失字段。
- 日度资金流只汇总富途返回的净流入和主力净流入。它是成交资金结构代理，不等同于新闻、社交情绪或未来涨跌方向。
- 财务报表只读接口支持利润表、资产负债表、现金流量表和关键指标四种固定类型。共同快照批量冻结四只标的最近两期关键指标，保留报告期、币种、会计准则、审计意见、字段 ID、同比与环比；不晚于当前日期之外的报告期、非有限数值和无数据报表会被过滤。
- 财务报表单次每个标的最多读取 10 期、每期最多保留 200 个有效字段；共同提示上下文只放每只标的最新一期、最多 40 个字段，并明确标记截断，完整结构仍保留在冻结快照中。
- 主营构成只读取富途返回的最新有效报告期，保留产品、行业、地区、业务四种披露维度、原始标签、营业收入、比例、币种和可选历史期间。共同提示上下文每个维度最多放 20 项；不同公司标签不自动合并，比例也不能跨维度相加。
- 主营构成接口执行本地 30 秒最多 30 次的硬上限，与富途公开的接口频率限制一致；批量调用复用一个 `OpenQuoteContext`。
- 基本面、技术指标、资金流、财务报表或主营构成接口任一失败时保留分层错误，不用其他来源静默补值；完整截面可标为 `degraded`，不影响可用分层继续参与研究。

## 安全门

- 唯一连接对象是行情用 `OpenQuoteContext`。
- 能力声明固定为 `execution_capability: none` 和 `live_trading_allowed: false`。
- 代码测试扫描并禁止交易上下文、交易解锁和下单 API。
- 任何未来模拟交易也必须进入独立纸面执行层，不能改变这个数据适配器的只读边界。

## 角色解释边界

- 基本面分析师必须区分快照估值字段、财报关键指标和完整三张报表，并保留报告期与币种口径；共同截面的关键指标不得冒充完整财报历史。
- 产业分析师比较 NAND、HDD、区域或业务收入结构时，必须保留公司原始披露标签、报告期和币种；系统不会自动断言两个近似名称属于同一业务。
- 技术分析师必须说明指标截止日期和样本数，指标是描述性证据而非预测。
- 新闻与情绪分析师优先使用带来源和时点的共享材料；没有新闻或社交数据时明确不可用，不能用资金流代替舆情。
