# 官方正文证据与可阅读事件卡 v1

本功能在 `c353d7144dda8559faf68439e5dc8a51bfcfefae` 候选上增加正文证据和确定性原文展示，不接入 AI 自动初评。原来的元数据监控、来源指纹、规则 sidecar、checkpoint、已阅、房间挂接和轮次草稿协议均不改变。

## 用户操作

打开「来源收件箱」，选择一条已导入的 NVDA 8-K 或 Micron 官方事件，在详情中的「官方正文证据」区域操作。

1. 查看状态不会访问来源网站。勾选范围确认框，再点「确认读取这条正文」，才安排这一条的读取。
2. 正文在独立后台任务中读取，页面显示等待、读取中、完成、部分内容或失败；不必启动讨论。
3. 读取后的卡片显示直接相关公司、实际读取范围、获取时间、原文段落和未知项。8-K 主文件的附件没有读取，会明确显示「当前证据不完整」。
4. 「正文证据版本」可以查看旧版本。每个段落的引用 ID 绑定不可变版本；复查不会覆盖旧引用。
5. 点击「复制本版正文研究材料」可复制标题、来源、范围、版本和段落引用。在目标房间的「共享资料」中手动加入后，复用已有 ChatGPT 协作任务包。下方原有「附加到房间」仍只附加原事件，不悄悄改变旧材料。

需要处理之后的新事件时，展开收件箱上方「正文自动补全（默认关闭，需单独确认）」。检查说明，勾选后点「确认启用新事件正文补全」。开启时只记录当前事件水位，历史事件不回填。不会开启原本关闭的元数据来源监控。

自动授权每次最多 20 分钟、合计 6 个正文操作；同时还以数据库记录限制所有手动和自动操作在滚动 20 分钟内合计最多 6 次。队列预约也计入上限。到期不开始新读取，在途正文读取接受截止时间控制；重启不恢复授权。不提供常驻无限正文采集。提前结束时按既有操作说明正常停止所属宿主控制台；关闭网页不会停止后台。

所有访问限于事件已经绑定的 NVDA 8-K 主 HTML、Micron `/news/press-release/<year>/<slug>/default.aspx`。不接受任意 URL，不跟随重定向，不遍历附件、历史目录、PDF、PPT 或其他公司。

## 实现与证据语义

`backend/document_evidence.py` 提供受限提取、版本保存、持久任务与一个宿主拥有的后台工作线程。`http_server.py` 只接入本地状态/明确确认接口及启动收尾；元数据 Runtime 不等待正文网络工作。默认关闭时工作线程不轮询数据库或来源。

- 复用 `material_ingest` 的公开地址解析及 DNS 固定连接、编码处理、FetchedResource；复用 `official_http` 的有界响应读取、取消和截止控制。不调用会向房间写材料的 `MaterialIngestService.fetch_url()`。
- 本版正文连接采用已有材料读取器的 DNS 固定直连传输，不继承浏览器登录或代理会话，不修改系统或进程代理设置。SEC 使用本机既有 SEC_USER_AGENT；没有配置时明确失败。此正文传输与元数据适配器的代理链路是不同验证项，尚未进行真实网络验收。
- 单操作最多一个 HTTP 请求，无自动重试或重定向请求；1.5 MB 响应上限，50,000 正文字符上限。字数截断会明确标为部分内容。正文没有可识别的文章容器、只有 NewsArticle 页头或找不到足够文本时，不生成伪全文。
- 正文网络/解析不持有 SQLite 写事务；版本插入和任务完成在同一事务中提交。正文失败不能回滚已经提交的来源事件。
- 重复确认返回已有任务，不再次 HTTP 读取；显式复查最少间隔 5 分钟。同一事件、URL、原始字节、正文及解析器版本形成幂等身份。相同内容复查保存最新任务结果而不重复增加版本；旧版本的首次获取时间保持原样。
- 429/503 的 Retry-After 保存并作用于同一发布者的其他事件，不能换事件绕过等待。失败或中断只在用户再次明确确认后重试；不对可能已发送的未知请求声称“恰好一次”。
- 单次网络预算为 12 秒或授权剩余时间的较小者。响应读取可以取消；系统 DNS 阻塞等未返回的底层调用仍可能超出收尾等待。超过 15 秒未停止会保留数据库 owner 并失败关闭，不宣称严格时限下全部进程退出已验收。
- HTML script/style/隐藏内容不执行；可见的恶意指令仍是无权限的外部文本，React 按文本展示。摘录不是 AI 总结，不给涨跌判断、交易授权或收益概率。

每个 `official_document_evidence_v1` 记录包含原事件 ID/指纹、请求及最终 URL、发布/修订时间（未知为 null）、本地获取时间、原始字节 SHA-256、规范正文 SHA-256、`official_html_blocks_v1` 解析器版本、读取范围/警告、未访问的正文链接清单、原文和稳定段落 ID。正文两种哈希不复用既有元数据哈希。段落按块顺序保存，表格行保留单元格分隔；没有进行财务表格语义识别。

## 数据与兼容

新增 `source_document_jobs` 和 `source_document_versions`，以及迁移标记 `official_document_evidence_v1`；版本记录有禁止 UPDATE/DELETE 的触发器。任务状态可以变化，正文版本不可变。没有更改旧事件、旧 sidecar、旧 checkpoint 或房间材料版本。

最低正文 reader 为本功能提交（支持上述两个 v1 格式）。旧候选只能处理原有元数据，不能展示或调度正文证据；不把“旧元数据仍存在”当作新功能可被旧版读取的证明。新增结构通过原有数据库迁移 manifest/shadow/授权流程识别，启动不自动升级已有数据库。本次只初始化隔离临时库，未迁移正式数据库、RC1 或 OnlineCollection 数据。

已有桌面离线/联网入口仍属于 c353d71 元数据候选。功能分支不自动改绑这些版本配置。实际试用正文版需另行准备匹配的新入口和明确的数据升级范围；不能复制旧配置中的候选 SHA 或构建哈希假装兼容。回退目标是升级前独立备份和匹配的旧代码/配置；不得删除 WAL 或将新库强行降级。
