# 核心弹窗键盘焦点闭环（2026-08-12）

## 结果

行动总览、新建房间和房间设置现在共享同一套模态焦点合同：打开后焦点进入弹窗，Tab 与 Shift+Tab 只在可见且可用的控件中循环，Escape 按既有业务状态关闭，关闭后恢复到仍可见的原始触发器。移动端侧栏触发器已经隐藏时，焦点会回到顶栏“打开房间列表”按钮，不再落到 `body`。

房间设置在保存期间仍保持原有忙碌态边界：Escape 不会绕过忙碌锁关闭窗口。此次改动没有改变房间、材料、正式轮、Provider、市场连接、用户决定或候选实验语义。

## 实现

- `frontend/src/useModalFocus.js`
  - 提供可复用的初始焦点、双向焦点循环、Escape、监听器清理和焦点恢复。
  - 可见性同时核验布局矩形、`display` 与 `visibility`，避免把移动端已隐藏但仍保留布局框的侧栏控件当成可见目标。
  - 在关闭后的动画帧中重新判断目标：桌面端优先恢复原始触发器，原始触发器隐藏时才使用显式备用目标。
- `frontend/src/components/ActionOverviewDrawer.jsx`
  - 关闭按钮成为初始焦点；遮罩不进入 Tab 顺序；关闭恢复精确触发位置。
- `frontend/src/components/Dialogs.jsx`
  - 新建房间在延迟初始化完成后安装焦点合同，房间名称成为初始焦点。
- `frontend/src/components/RoomSettingsDialog.jsx`
  - 房间名称成为初始焦点，并保留忙碌时不可关闭的约束。
- `frontend/src/App.jsx`
  - 为移动端侧栏触发路径提供稳定、可见的顶栏焦点备用目标。
- `frontend/tests/modalFocus.test.js`
  - 固定循环索引、计算样式可见性、延迟挂载、忙碌态、遮罩 Tab 顺序和三处宿主接线。
