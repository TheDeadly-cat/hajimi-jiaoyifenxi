# 交易分析工作区

这个工作区同时保留两个边界清晰的项目：

- `ai_collaboration_studio/`：主产品。通用多 AI 共创群聊，交易研究只是首个专业场景。
- `TradingAgents/`：上游交易智能体研究框架。用于吸收分析师、辩论、交易员和风控流程，不作为主产品外壳。

首个可验证样板是“交易研究 / 美股”分类下的“美国存储产业投资委员会”，研究标的为 `US.MU`、`US.SNDK`、`US.WDC`、`US.STX`。

安全边界：只进行研究、回测和模拟决策，不连接真实下单、支付或资金动作。

启动 AI 共创室：双击 `run_ai_collaboration_studio.cmd`。脚本会先探测 `http://127.0.0.1:8770/api/health`；已有健康服务时只打开浏览器，否则从 `ai_collaboration_studio/` 工作目录启动服务，健康后再打开 `http://127.0.0.1:8770/`。

富途 OpenD 与 SEC EDGAR 都是条件式只读数据源：只有本机 OpenD、行情权限和合规 `SEC_USER_AGENT` 分别就绪时，对应证据才可用；否则系统明确显示离线或不可用，不补造行情或申报。适配层没有交易上下文、解锁交易、委托或下单能力。
